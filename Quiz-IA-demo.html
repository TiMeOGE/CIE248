Deux façons d'essayer.

1. La démo, tout de suite

Choisis Démo incluse, sélectionne 5, 10 ou 15 questions, puis lance le quiz. Les questions portent sur le cours d'exemple et sont préparées à l'avance. Ce mode fonctionne hors ligne et n'utilise pas d'IA.

2. Tes cours, avec une vraie génération IA

  1. Décompresse le dossier complet du prototype.
  2. Copie .env.example en .env. Ajoute ta clé dans OPENAI_API_KEY=....
  3. Lance demarrer-windows.bat sous Windows, ou bash demarrer-linux.sh sous Linux / Raspberry Pi. Python 3.10 ou plus est nécessaire.
  4. Ouvre http://127.0.0.1:8000, puis utilise l'onglet Mon document.

Le modèle est configurable dans .env. Le site tourne sur ton ordinateur ou Raspberry Pi ; l'IA utilisée par cette version est distante, via l'API OpenAI.

Avant d'envoyer un cours : utilise seulement un document que tu as le droit de transmettre, sans noms d'élèves ni données sensibles. Les appels API peuvent être facturés. Un abonnement ChatGPT ne configure pas automatiquement cette API.

Ce que le prototype ne fait pas encore

Pas de comptes, d'historique, de plateforme enseignant ni de validation pédagogique automatique. Pas de scans ou d'images seuls. Les extraits sont vérifiés dans le texte du cours, mais les questions et les corrections doivent encore être relues. Le quiz en cours disparaît au rechargement.

Le serveur ne sauvegarde pas les cours sur disque. En mode API, le texte est transmis à OpenAI : ce n'est pas un traitement 100 % local. Ce serveur est prévu pour une démo locale, pas une mise en ligne publique.
